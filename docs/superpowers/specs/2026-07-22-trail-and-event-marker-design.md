# 航跡與事件標記精簡設計

日期：2026-07-22

## 目標

降低海戰畫面中的視覺干擾，讓作戰單位保持為主要視覺焦點，同時保留使用者主動查看航線與辨識當前事件位置的能力。

目前地圖上的白色圓圈是歷史事件位置標記，不是作戰單位。當多個事件位於相近海域時，標記會重疊；所有航線長時間殘留也會形成密集路網。本設計分別處理這兩個問題。

## 航跡圖層

### 控制方式

- 在播放控制區加入「航跡：關／開」切換按鈕。
- 每次載入戰役文件時，航跡一律重設為關閉。
- 關閉時不顯示過去、現在或未來的任何 movement path。
- 切換航跡不改變播放、時間軸、單位位置或 Follow 狀態。

### 開啟後的顯示規則

- 只顯示當下正在進行的 movement path。
- 路徑沿單位行進進度逐步顯示，不預先揭露尚未走過的區段。
- movement 完成後，完整路徑保留並在 2.5 秒內淡出，之後隱藏。
- 同一時間有多個 active movements 時，各自獨立顯示與淡出。
- inferred movement 沿用虛線樣式；精確或 approximate movement 使用實線。

### 播放與跳轉語意

- 正常向前播放時才執行 2.5 秒的完成淡出。
- 使用 scrubber、上一事件、下一事件、Reset 或程式化 `seek()` 時，不補播過去的淡出動畫。
- seek 後僅重建目標時間點仍為 active 的路徑；所有已完成或尚未開始的路徑立即隱藏。
- 向後 seek 後重新播放，movement 再次完成時可以重新觸發一次淡出。
- 關閉航跡時立即取消所有進行中的路徑淡出並隱藏路徑。

## 事件脈衝信標

### 外觀與生命週期

- 移除目前白色圓形事件標記及其中容易與單位混淆的圖示。
- 當事件開始時，在事件座標顯示小型菱形信標。
- 信標使用事件類型對應的簡潔符號；事件資訊仍由事件卡承擔，地圖上不重複顯示長標題、時間與信心文字。
- 信標出現時外圈脈衝兩次，之後保持小型靜態菱形直到事件結束。
- 事件結束時於 400 毫秒內淡出並移除。
- 尚未開始與已結束的事件不保留地圖標記。

### 相近事件群聚

- 每次重新投影時，以螢幕座標判斷 active event beacons。
- 中心距離小於 28 CSS pixels 的信標合併為單一群聚信標。
- 群聚位置使用成員投影座標的平均值，並顯示 active event 數量。
- 群聚只影響地圖標記，不合併事件卡、時間軸項目或事件狀態。
- 當事件結束、地圖縮放或平移使距離超過門檻時，群聚立即重新計算並拆分。

## 動態效果與無障礙

- `prefers-reduced-motion: reduce` 時，停用信標脈衝與航跡淡出動畫。
- reduced-motion 模式下，事件信標直接顯示為靜態菱形，事件結束後立即隱藏。
- reduced-motion 模式下，完成航跡立即隱藏。
- 航跡切換按鈕使用 `aria-pressed`，文字清楚反映目前的開關狀態。
- 信標不接收鍵盤焦點；完整事件資訊仍可由時間軸與事件卡存取。

## 元件與資料流

### Renderer controller

`renderBattle()` 的 controller 新增航跡顯示狀態與切換入口。每一幀根據 timeline sample 判定 active movements；正常播放跨越 movement 結束點時建立短暫的 fading trail 狀態。`seek()`、`reset()`、文件替換與 `destroy()` 必須清除暫態淡出狀態及計時器。

### Playback controls

航跡按鈕由既有控制列管理，生命週期與 speed、follow 控制一致。重新 wire 或替換文件時不可累積事件監聽器。

### Event beacon layout

事件信標仍使用 SVG overlay，但渲染為外層定位 group、內層菱形與脈衝 ring。群聚計算是一個純函式：輸入 active event 投影點與 28px 門檻，輸出單點或群聚；方便以 Node 測試覆蓋，不依賴 Leaflet DOM。

## 錯誤與邊界處理

- 缺少可用事件座標時不建立信標，事件卡與時間軸仍正常運作。
- 零長度 movement 在 timeline 正規化後，仍依正常完成規則觸發一次淡出。
- 互相重疊的 movements 依既有「較晚 movement 優先」規則顯示單位位置，但每條 active path 可獨立呈現。
- 文件驗證失敗、JSON 解析失敗或 controller 銷毀後，不得留下航跡、信標、動畫 frame 或 timeout。

## 測試與驗收

- 航跡預設關閉，重新載入文件後恢復關閉。
- 開啟航跡不改變目前播放時間與單位位置。
- active path 依進度揭露；完成後淡出 2.5 秒並隱藏。
- seek、Reset、上一／下一事件不保留歷史航跡。
- 關閉航跡會取消進行中的淡出。
- inferred path 保持虛線且揭露進度正常。
- event beacon 僅在事件 active 時存在，開始脈衝兩次、結束淡出 400ms。
- 28px 內的 active events 合併並顯示正確數量；縮放、平移或事件結束後可拆分。
- reduced-motion 模式沒有脈衝或淡出動畫。
- 文件替換與 destroy 不遺留 listener、RAF 或 timeout。
- 桌面與手機寬度下，信標不遮蔽主要控制項，航跡按鈕可辨識且可操作。

## 不在此次範圍

- 不修改戰役 JSON schema 或要求 LLM 產生新的 marker 欄位。
- 不加入逐事件自訂信標 SVG。
- 不改變事件卡、timeline compiler 的歷史排序或作戰單位 SVG catalog。
- 不實作持久化的使用者航跡偏好；每份文件皆預設關閉。
